# فروشگاه اینترنتی با Django

یک فروشگاه اینترنتی ساده و کامل که با Django پیاده‌سازی شده است. این پروژه به عنوان پروژه دانشگاهی توسعه داده شده و شامل امکانات اصلی یک فروشگاه آنلاین می‌باشد.

## امکانات پروژه

- سیستم ثبت‌نام و ورود کاربران
- نمایش محصولات همراه با جستجو و دسته‌بندی
- سبد خرید (افزودن، حذف و مشاهده محصولات)
- محاسبه خودکار مجموع قیمت محصولات
- پنل مدیریت محصولات از طریق Django Admin
- استفاده از Django ORM برای مدیریت پایگاه داده
- طراحی صفحات با HTML و CSS

## تکنولوژی‌های استفاده شده

- Python
- Django
- HTML / CSS
- SQLite (به عنوان پایگاه داده پیش‌فرض)

## نحوه اجرای پروژه

1. مخزن را کلون کنید:
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME

2. محیط مجازی بسازید و فعال کنید:
python -m venv venv

ویندوز:
venv\Scripts\activate

لینوکس / مک:
source venv/bin/activate

3. پکیج‌های مورد نیاز را نصب کنید:
pip install -r requirements.txt

4. مایگریشن‌ها را اجرا کنید:
python manage.py migrate

5. سرور را اجرا کنید:
python manage.py runserver

سپس به آدرس http://127.0.0.1:8000 بروید.
